About sources

OmniShelf uses public search APIs when their terms and access allow it. AniList's published API terms restrict using its API in competing anime/manga trackers without authorization, so this build does not call that API directly. You can import your own exported lists from AniList or other services, and add or upload missing content manually. Source links and attribution are shown with imported catalogue records.
